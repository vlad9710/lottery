# Игровые разборы

Калькуляторы для мини-игр.

Сайт: https://vlad9710.github.io/lottery/

`index.html` — калькулятор моментальной лотереи 3×3: какую клетку открыть и какую линию выбрать, плюс общая статистика игроков.

## Статистика

Результаты партий хранятся в Google Таблице. Между сайтом и таблицей — скрипт Apps Script из `apps-script/Code.gs`:
он проверяет каждую партию (цифры без повторов, сумма возможна, очки по таблице выплат), не принимает партии
с одного устройства чаще раза в 15 секунд и считает сводную статистику. Адрес скрипта прописан в `index.html` (`SCRIPT_URL`).

Раньше статистика хранилась в Supabase (`supabase.sql`, `migrations/`); старые партии перенесены в таблицу.
