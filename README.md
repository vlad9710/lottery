# Игровые разборы

Калькуляторы для мини-игр.

- `lottery.html` — моментальная лотерея 3×3: какую клетку открыть и какую линию выбрать, плюс общая статистика игроков.
- `index.html` — главная страница со списком разборов.

## Статистика

Результаты партий хранятся в Supabase. Схема базы — в `supabase.sql` (выполнить один раз в SQL Editor проекта).
Адрес проекта и публичный ключ `anon` прописаны в `lottery.html` (`SUPABASE_URL`, `SUPABASE_KEY`).
Ключ `anon` публичный по задумке: через него можно только добавлять партии и читать сводную статистику.
