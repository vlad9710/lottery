# Игровые разборы

Калькуляторы для мини-игр.

Сайт: https://vlad9710.github.io/lottery/

`index.html` — калькулятор моментальной лотереи 3×3: какую клетку открыть и какую линию выбрать, плюс общая статистика игроков.

## Статистика

Результаты партий хранятся в Supabase. Схема базы — в `supabase.sql` (выполнить один раз в SQL Editor проекта).
Адрес проекта и публичный ключ `anon` прописаны в `index.html` (`SUPABASE_URL`, `SUPABASE_KEY`).
Ключ `anon` публичный по задумке: через него можно только добавлять партии и читать сводную статистику.
